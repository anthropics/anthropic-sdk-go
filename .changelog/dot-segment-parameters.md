Only the routes that need a workspace ID return the error for a googlecloud workspace ID such as ";x". An empty region passed to vertex.WithCredentials, which was sent as "/locations//publishers", is now an error too, and vertex.WithGoogleAuth panics for a region such as ";x", as it does for an empty one
